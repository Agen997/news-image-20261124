Sum up the world's news of Tuesday 24 November 2026 in one image: a
newspaper front page — masthead dated 24 November 2026, the Huawei verdict
as the lead story, Ukraine's strikes on Russian ships, NATO's warning to
defend space, the US losing measles-free status, Sanofi's $41bn Insmed
deal, the Turkish helicopter crash, plus the day's markets and sport. The
image is drawn programmatically with Python (PIL) so every headline is
spelled correctly, and `main.py` copies it deterministically to
`/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
# regenerates the image first with: python3 draw.py
```
